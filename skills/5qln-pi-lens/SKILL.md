# Skill: 5qln-pi-lens

**Domain:** Sub-phase exploration via `/5qln-lens` on Pi.
**Use when:** one phase needs a deeper pass before transitioning to the next.

---

## THE HOLOGRAPHIC LAW

`XY := X within Y` — every phase contains all five phases.

The cycle S → G → Q → P → V is the surface. Each phase is itself a full lawful cell. When you need to deepen formation at one phase, enter a sub-phase lens — you are running the cell at a smaller scale without leaving the parent phase.

The 5QLN extension exposes this via `/5qln-lens <SubPhase>`. There are 25 sub-phases (5 per phase).

---

## INVOCATION

```
/5qln-lens SG    # enter the SG lens
/5qln-lens       # exit the current lens
```

Sub-phase IDs are two-letter pairs: first letter = parent phase, second letter = lens. For example, **SG** means "the G lens applied within S" — exploring the *structure* (G) of the *spark* (S).

The kernel rejects mismatched lenses. If you are in S, you can enter SS / SG / SQ / SP / SV — but not GG.

---

## SERVE-vs-BE RULE

Sub-phase input **serves the formation of the parent phase's output but does not overwrite it.**

- At S, the question line is X. If you enter SG and the human says "this branches into structure and feeling," that input enriches the trail of X but **X itself remains the original question**.
- Only main-phase input refines the output. Lens input is a side-trail in service of the main thread.

This is by design. The lenses let you go deep without losing the spark.

## WHEN TO OPEN A LENS

- **The phase output is too vague.** Enter the lens whose question matches the gap. Example: at S, X is fuzzy → `/5qln-lens SG` to expose its structure.
- **Resonance is suspect.** At Q, run `/5qln-lens QS` to bring fresh doubt.
- **The artifact at V feels rote.** `/5qln-lens VS` to test whether B'' is surprising.
- **You are about to transition prematurely.** Run a lens first; transition after.

## WHEN TO CLOSE A LENS

- Lens question has been answered.
- Two consecutive lens inputs and the parent output is stable.
- You are about to transition phase. Close the lens before transitioning.

`/5qln-lens` (no argument) exits.

---

## LENS DEPTH — the field reads it

`session_flow` reports `field.lensDepth` — how many distinct lenses have been used in this cycle. A high lens depth on a single phase means the formation is being given proper care. A zero lens depth across a complex cycle is a signal that the phases were rushed.
